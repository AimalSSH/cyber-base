# Инструменты для исследования межпроцессного взаимодействия и чтения памяти
Набор утилит для демонстрации чтения памяти между процессами в Linux.

## Состав
- `buffer_victim.py` — процесс-жертва, создающий буфер с маркером в памяти
- `buffer_attacker.py` — процесс-атакующий, читающий память жертвы
- `inspect_maps.py` — просмотр карты памяти процесса (`/proc/<pid>/maps`)
- `enum_processes.py` — перечисление процессов, их файлов и сокетов

## Использование

### 1. Запуск жертвы
```bash
python3 buffer_victim.py
```
Выведет PID и адрес буфера:
```
victim: pid=12345 marker=SECRET_MARKER_AIMAL_1234567890 addr=0x7f8a4c000000 size=1048576
```

### 2. Просмотр сегментов памяти жертвы
```bash
python3 inspect_maps.py 12345
```
Покажет все сегменты с правами чтения-записи (`rw`).

### 3. Атака на память жертвы
```bash
python3 buffer_attacker.py 12345 0x7f8a4c000000 128
```
Где:
- `12345` — PID жертвы
- `0x7f8a4c000000` — адрес буфера
- `128` — количество байт для чтения

Атакующий попытается прочитать память через:
1. `process_vm_readv()` (системный вызов)
2. `/proc/<pid>/mem` (если первый метод не сработал)

### 4. Перечисление процессов
```bash
python3 enum_processes.py
```
Выводит JSON со списком всех процессов, их открытыми файлами и сетевыми соединениями.

## Требования

- Python 3
- Библиотека psutil
- Права доступа к процессам (зависит от `ptrace_scope`)

## Примечания

- Если чтение не работает, проверьте:
  ```bash
  cat /proc/sys/kernel/yama/ptrace_scope
  ```
  Рекомендуется установить `0` для лабораторной среды:
  ```bash
  echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope
  ```
- Для работы с чужими процессами может потребоваться `sudo`
- Инструменты предназначены для образовательных целей и исследования работы памяти в Linux
