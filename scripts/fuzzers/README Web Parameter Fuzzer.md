# Web Parameter Fuzzer

Безопасный инструмент для тестирования веб-параметров и форм.

## Отказ от ответственности

Данный инструмент предназначен только для образовательных целей и тестирования систем, где у вас есть  разрешение. Использование без разрешения может нарушать законы о компьютерной безопасности. Автор не несет ответственности за неправомерное использование.

## Описание

Инструмент выполняет фаззинг веб-параметров для выявления:
- Ошибок SQL
- Ошибок сервера (500+)
- Утечек данных (большие ответы)
- Отладочной информации
- Нестандартных ответов

## Требования

- Python 3.6 или выше
- Библиотеки: requests, beautifulsoup4

## Использование

Базовый синтаксис
`python web_fuzzer.py -u <URL>`

## Параметры командной строки

|     Параметр    | Длинная опция |                        Описание                       |                  По умолчанию                  |   |
|:---------------:|:-------------:|:-----------------------------------------------------:|:----------------------------------------------:|---|
| -u              | --url         | Целевой URL для тестирования                          | Обязательный                                   |   |
| -d              | --delay       | Задержка между запросами (сек)                        | 0.5                                            |   |
| -t              | --timeout     | Таймаут HTTP запроса (сек)                            | 10                                             |   |
| --no-forms      | -             | Не тестировать HTML формы                             | False                                          |   |
| --no-url-params | -             | Не тестировать параметры URL                          | False                                          |   |
| -v              | --verbose     | Подробный вывод                                       | False                                          |   |
| --seed-value    | -             | Значение для воспроизводимости случайных мутаций      | 42                                             |   |
| --keywords      | -             | Ключевые слова для поиска в ответе                    | exception traceback error segfault nullpointer |   |
| -v              | --verbose     | Подробный вывод всех запросов                         | False                                          |   |
| --no-save       | -             | Не сохранять интересные payload'ы (только логировать) | False                                          |   |

## Примеры использования

1. Базовый фаззинг:
```bash
python web_fuzzer.py -u "https://example.com/page.php?id=1&cat=2"
```

2. С задержкой для предотвращения перегрузки:
```bash
python web_fuzzer.py -u "http://localhost:3000/search?q=test" -d 1.0
```

3. Только параметры URL (без форм):
```bash
python web_fuzzer.py -u "https://test.com/api?id=1" --no-forms
```

4. Только формы (без URL параметров):
```bash
python web_fuzzer.py -u "https://example.com/contact" --no-url-params
```

5. Детальный вывод:
```bash
python web_fuzzer.py -u "http://localhost:8080/products?id=1" -v
```

## Как это работает
1. Извлечение параметров: Извлекает параметры из URL
2. Извлечение форм: Парсит HTML для поиска форм
3. Фаззинг: Последовательно подставляет тестовые значения
4. Анализ: Проверяет ответы на аномалии

## Типы проверяемых аномалий
- SQL Error: Ошибки SQL в ответе
- Server Error: HTTP статус 500+
- Not Found: HTTP статус 404
- Large Response: Подозрительно большой ответ (>100KB)
- Debug Information: Отладочная информация в ответе
