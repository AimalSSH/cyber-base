# Port Scanner - Сканер сетевых портов
Инструмент командной строки для сканирования сетевых портов с использованием TCP SYN сканирования.

## Возможности
- TCP SYN сканирование - быстрый и эффективный метод сканирования портов
- Гибкая настройка портов - сканирование отдельных портов, диапазонов или списков
- Проверка доступности хоста - опциональная проверка хоста через ICMP ping
- Экспорт результатов - вывод в удобочитаемом или JSON формате
- Настройка таймаута - возможность изменения времени ожидания ответа

## Требования
- Python 3.6+
- Scapy
- Права root/administrator для отправки сырых сетевых пакетов

## Установка
```bash
pip install scapy
```

## Использование

### Основной синтаксис

```bash
sudo python3 port_scanner.py --host <IP_или_домен> [опции]
```

### Примеры

1. Сканирование одного порта:
```bash
sudo python3 port_scanner.py --host 192.168.1.1 --port 80
```

2. Сканирование диапазона портов:
```bash
sudo python3 port_scanner.py --host example.com --ports 20-100
```

3. Сканирование списка портов:
```bash
sudo python3 port_scanner.py --host 10.0.0.1 --ports 80,443,22,8080
```

4. Сканирование с проверкой доступности хоста:
```bash
sudo python3 port_scanner.py --host 8.8.8.8 --ports 1-1024 --check
```

5. Экспорт результатов в JSON:
```bash
sudo python3 port_scanner.py --host example.com --ports 80,443 --json
```

6. Настройка таймаута:
```bash
sudo python3 port_scanner.py --host 192.168.1.1 --port 22 --timeout 2.5
```

## Аргументы командной строки

| Аргумент | Описание | Обязательный |
|----------|----------|--------------|
| `--host` | Целевой хост (IP адрес или доменное имя) | Да |
| `--port` | Сканировать конкретный порт (1-65535) | Да* |
| `--ports` | Диапазон портов (формат: 20-100) или список (80,443,22) | Да* |
| `--check` | Проверить доступность хоста (ping) перед сканированием | Нет |
| `--json` | Экспорт результатов в JSON формате | Нет |
| `--timeout` | Таймаут соединения в секундах (по умолчанию: 1.0) | Нет |

\* Обязателен один из: `--port` или `--ports`

## Результаты сканирования

При сканировании порт может получить один из следующих статусов:

- open - порт открыт и принимает соединения
- closed - порт закрыт (получен RST пакет)
- filtered - порт фильтруется (нет ответа или получен ICMP ошибка)
- unexpected_flags - получены неожиданные TCP флаги
- icmp_error - получен ICMP ответ вместо TCP
- error - произошла ошибка при сканировании

## Примеры вывода

```

[+] Порт 80: открыт
[-] Порт 443: закрыт
[-] Порт 22: фильтруется или не отвечает
```

## Примечания

1. Права доступа: Для работы с сырыми сокетами требуются права root/administrator
2. Скорость сканирования: Между сканированиями портов добавлена задержка 0.1 секунды для снижения нагрузки на сеть
3. Обработка SYN-ACK: При обнаружении открытого порта автоматически отправляется RST пакет для корректного завершения соединения
4. Разрешение DNS: Доменные имена автоматически преобразуются в IP адреса

## Ограничения
- Не поддерживает IPv6
- Требует установленных библиотек Scapy
- Может блокироваться файрволами и системами обнаружения вторжений

## Устранение неполадок

### Ошибка разрешения домена
```
Ошибка: Не удается разрешить hostname: example.com
```
Решение: Проверьте подключение к интернету и правильность написания домена.

### Ошибка "Permission denied"
```
Permission denied
```
Решение: Запустите скрипт с правами root/sudo.

### Медленное сканирование
Решение: Уменьшите значение таймаута с помощью параметра `--timeout` или отключите проверку доступности хоста.
